Multimodal Deepfake Detection

Deep Learning System for Image & Video Deepfake Analysis

Developed a Deep Learning system for detecting deepfakes in images and videos using spatial and temporal analysis with explainability features.

View on GitHub

Problem

Deepfake technology is increasingly sophisticated, making manual detection unreliable. Automated systems are needed to identify manipulated media at scale.

Solution

A multimodal deep learning architecture combining spatial (CNN/ResNet-50) and temporal (BiLSTM + Attention) analysis with Grad-CAM explainability.

Key Features

Spatial Analysis

CNN/ResNet-50 backbone extracts spatial features from individual video frames.

Temporal Analysis

BiLSTM processes frame sequences to capture temporal inconsistencies in deepfake videos.

Attention Mechanism

Temporal attention focuses on the most discriminative frames for prediction.

Explainability

Grad-CAM visualizes image areas contributing to model predictions for interpretable results.
