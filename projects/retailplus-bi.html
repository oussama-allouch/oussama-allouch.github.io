Problem

Retail environments generate large volumes of fragmented transactional data. Traditional systems make it difficult to provide consolidated real-time analytics across stores, products, customers and supply chains.

Solution

RetailPlus BI provides an end-to-end modern Data Platform combining historical Batch processing with real-time Streaming. The system implements a Medallion Architecture (Bronze → Silver → Gold) to progressively refine data quality and produce analytics-ready datasets.

Key Features

Hybrid Data Ingestion

Historical CSV files are processed using PySpark Batch while real-time transactions are published through Apache Kafka.

Real-Time Processing

PySpark Structured Streaming consumes Kafka events using micro-batches for near real-time data availability.

Medallion Architecture

Bronze (raw ingested data) → Silver (cleaned, typed and validated data) → Gold (analytics-ready Star Schema).

Data Quality

Invalid value detection, null detection, duplicate removal, referential integrity validation, rejected-record isolation and audit metadata.

Data Warehouse

PostgreSQL analytical warehouse using Kimball dimensional modeling with fact_sales and dimensions for time, store, product, customer and supplier.

Pipeline Orchestration

Apache Airflow orchestrates Bronze → Silver → Gold using multiple DAGs and an end-to-end master DAG.

Containerization

Complete platform runs using Docker Compose with services for Kafka, Zookeeper, Spark Master/Worker, PostgreSQL, Airflow, and more.

BI Dashboard

Streamlit dashboard with 7 analytical views: Executive Overview, Store Performance, Sales Analytics, Products & Categories, Customer Loyalty, Inventory & Supply Chain, Returns & Quality.

Data Engineering

The platform implements both batch and streaming data ingestion. PySpark processes historical CSV files through distributed transformations, while PySpark Structured Streaming consumes real-time events from Apache Kafka.

  • Batch ingestion of historical CSV datasets
  • Real-time streaming ingestion via Apache Kafka
  • Distributed processing with PySpark
  • Data cleaning and type casting
  • Data quality validation and rejected-record management
  • Referential integrity validation
  • Data lineage and ingestion traceability

Data Warehouse

The Gold layer implements a PostgreSQL analytical Data Warehouse using Kimball dimensional modeling.

  • Kimball dimensional modeling methodology
  • Star Schema design
  • Fact table: fact_sales
  • Dimensions: time, store, product, customer, supplier
  • Surrogate keys for dimension management
  • Analytical SQL views for BI consumption

Orchestration

Apache Airflow automates the complete data pipeline workflow through multiple specialized DAGs.

  • Master DAG for end-to-end orchestration
  • Bronze DAG for raw data ingestion
  • Silver DAG for data cleaning and validation
  • Gold DAG for warehouse loading

DevOps

The complete infrastructure is containerized using Docker Compose for reproducible deployments.

  • Docker Compose multi-container architecture
  • Persistent volumes for data durability
  • Docker networking for service communication
  • 8 interconnected services

Analytics
